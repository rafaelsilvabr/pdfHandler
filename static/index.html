About PDF Handler

Small tools.
A simpler workday.

A self-hosted home for the everyday document tasks. Built to be useful, easy to run, and entirely yours.

01 / The idea

A workspace that stays yours.

PDF Handler brings eight focused document tools into one quiet workspace. Merge a report, split a long document, compress an attachment, or put a page the right way up.

Originally built for a homelab, it runs on your own infrastructure. One small application serves the tools and the interface, with no accounts to create or external services to connect.

01

Everyday work, covered.

Merge, split, compress, rotate, convert images, protect, and unlock. Each tool does one useful job.

02

Your infrastructure. Your control.

Documents are processed by the server running this instance. You choose where that server lives and who can reach it.

03

Only here while you need it.

Uploaded files are handled in temporary storage and deleted when the request completes. Save the result wherever you keep your documents.
